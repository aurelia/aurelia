# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, Discord, Discourse, Stack Overflow, or other public channels.

Use GitHub's private vulnerability reporting flow for this repository: https://github.com/aurelia/aurelia/security/advisories

Please fill in the form as per required by Github.

Please give the maintainers a reasonable amount of time to investigate and remediate the issue before making any public disclosure.

## Supported Versions

Security fixes are generally only provided for the latest supported release line of Aurelia 2 in this repository.

| Version | Supported |
| ------- | --------- |
| Current Aurelia 2 release line | :white_check_mark: |
| Older Aurelia 2 release lines | :x: |
| Aurelia 1 / external repositories | :x: |

If a vulnerability affects an older version, maintainers may still choose to provide guidance or a fix, but this should not be assumed.

## Response Expectations

The maintainers will aim to:

- Acknowledge receipt of a report within 7 days
- Provide a follow-up status update after initial triage
- Coordinate disclosure after a fix or mitigation is available

Response times may vary depending on report quality, maintainer availability, and the complexity of the issue.
