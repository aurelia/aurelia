# AUR0724

### **Error message**

Template compilation error in element "{{0}}": <{{1}}> is a deferred dependency, but no element named "{{1}}" is registered. Deferred elements can only be used inside a template controller that defers its content, such as [defer], and the loaded module must define an element named "{{1}}".

### **Parameters**

1. `name`: The name of the element whose template is being compiled.
2. `element`: The tag name of the deferred dependency.

### Error explanation

A component lists `<{{1}}>` in its `deferredDependencies`, either directly on its definition or with `<import from="..." defer>`. Deferred elements are only registered when a [`defer` block](../../../templates/deferred-rendering.md) that uses them renders, so the compiler can only resolve them inside such a block, after their loader has run.

This error is only thrown in development builds. In production the element would render as an unknown element.

### Common causes

- The element is used outside of any `defer` block, so it's compiled with the rest of the template before it's loaded.
- The loaded module defines the element under another name than the key in `deferredDependencies`. With the conventions plugin, the key comes from the file name, so a file `heavy-chart.ts` whose class is `@customElement('sales-chart')` loads an element named `sales-chart`, not `heavy-chart`.
- The loader resolves to something that doesn't register the element, for example a module whose element class isn't exported.

### How to fix

- Move the element inside a `defer` block, or import it normally if it's needed on the first render.
- Make the key in `deferredDependencies` match the name the element is defined with, or register the element under the name you use with the `as` of the deferred `<import>`.

```html
<!-- Error: heavy-chart is deferred but used outside a defer block -->
<import from="./heavy-chart" defer></import>
<heavy-chart></heavy-chart>

<!-- Correct -->
<import from="./heavy-chart" defer></import>
<section defer="viewport">
  <heavy-chart></heavy-chart>
</section>
<div defer-placeholder>Chart</div>

<!-- Correct: "as" registers the loaded element under the name the template uses -->
<import from="./heavy-chart" defer as="sales-chart"></import>
<section defer="viewport">
  <sales-chart></sales-chart>
</section>
<div defer-placeholder>Chart</div>
```
