# AUR3180: Static Route Path Contains Instruction Syntax

## Warning Message

`AUR3180: Route path "%s" on %s contains router instruction syntax in a static segment. For reloadable links, configure an encoded, non-colliding path (for example, "a%2Bb" for "a+b"). Check that the chosen address does not already belong to another route.`

## Description

A static segment of a configured route contains characters that have another meaning in routing instructions or URLs. For example, `+` separates sibling viewport instructions and `@` selects a viewport. A route configured as `a+b` therefore cannot rely on that spelling behaving as a single literal segment in links and direct URL entry.

The development warning points to the configured path. It does not change route recognition, encode the path automatically, or create an additional address for it. Parameter declarations such as `:id` and wildcard declarations such as `*path` retain their own syntax.

## Solutions

Choose an unambiguous public address. If the punctuation belongs in the address, configure its encoded spelling:

```typescript
routes: [
  { id: 'comparison', path: 'a%2Bb', component: Comparison },
]
```

```html
<a load="comparison">Compare A and B</a>
```

Before changing an existing path, check whether another route already uses the encoded address. An explicit `a%2Bb` route or a parameterized route such as `:name` may already handle it. Giving that address to a different route can send published links and bookmarks to another component.

For values supplied to dynamic parameters, pass the original value in a structured instruction; the router encodes it during path generation:

```typescript
await router.load({
  component: 'comparison-detail',
  params: { name: 'a+b' },
});
```

Here `comparison-detail` is a route ID with a path such as `comparisons/:name`. Do not pre-encode the parameter value. Verify the generated link through ordinary navigation, direct entry, and reload. See [route expression syntax](../../../router/route-expression-syntax.md) for the roles of reserved characters.
