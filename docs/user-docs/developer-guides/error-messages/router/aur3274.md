# AUR3274: Conflicting Navigation Attributes

## Error Message

`AUR3274: The url attribute must be the only navigation attribute on its element. Remove the accompanying load or href attribute.`

## Description

The `url` attribute was placed on an element that also has `load` or the router's `href` custom attribute. These attributes resolve destinations differently, and each writes a link and handles its click. Combining them would make binding order decide which destination is used.

## Solutions

Choose the attribute that matches the destination. Use `url` for a reference relative to the current application URL:

```html
<a url="../reports">Reports</a>
```

The `url` attribute writes the `href` for you, so remove an authored `href` from that element. Native attributes such as `target` and `download` can remain.

Use `load` when navigating to a configured route with parameters or from a particular routing context:

```html
<a load="route: report; params.bind: { id: reportId }">Report</a>
```

For an external site or another document, use a [native link](../../../router/navigating.md#bypassing-the-href-custom-attribute). Existing `load` and `href` combinations are unaffected when `url` is absent.
