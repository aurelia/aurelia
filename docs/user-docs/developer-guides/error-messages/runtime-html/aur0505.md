# AUR0505: Controller in an Unexpected Deactivation State

## Error Message

`AUR0505: Controller at <controller> is in an unexpected state: <state> during deactivation.`

## Description

Aurelia found a controller state outside the supported deactivation transitions. It coordinates ordinary overlap by joining a deactivation already in progress and completing immediately for an inactive controller. A deactivation requested during activation cancels the request to become active while Aurelia waits for lifecycle work that already started. Errors from that work are still reported.

Check any integration code that controls the controller lifecycle directly. It may have changed `controller.state` or called a controller method outside its lifecycle contract. If this occurs through standard routing or template composition, capture a minimal reproduction for the Aurelia team.

## What to Check

- Find direct writes to `controller.state` and remove them.
- Keep each low-level controller under one lifecycle owner. Await its current transition before starting unrelated work.
- Record `<controller>`, `<state>`, and the full stack trace.
