# AUR0505: Controller in an Unexpected Deactivation State

## Error Message

`AUR0505: Controller at <controller> is in an unexpected state: <state> during deactivation.`

## Description

Aurelia found a controller state outside the supported deactivation transitions. Ordinary overlap is coordinated automatically. Deactivation can compensate an active activation. It can also join an existing deactivation or complete immediately for an inactive controller.

This error usually points to low-level integration code that changed controller state or invoked controller internals outside their lifecycle contract. A reproduction that uses standard routing or template composition indicates a framework consistency issue.

## What to Check

- Find direct writes to `controller.state` and remove them.
- Keep each low-level controller under one lifecycle owner. Await its current transition before starting unrelated work.
- Record `<controller>`, `<state>`, and the full stack trace. Create a minimal reproduction when Aurelia produced the state through its public composition APIs.
