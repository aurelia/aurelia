# AUR0509: Lifecycle Dependency Cycle

## Error Message

`AUR0509: Controller at <controller> created a lifecycle dependency cycle: <reason>.`

## Description

Aurelia detected a controller transition that would wait for itself. This can happen when a lifecycle hook returns its controller's current activation or deactivation result. It can also happen when a child hook returns an ancestor transition that is waiting for the child.

Aurelia rejects the lifecycle request with AUR0509. If the error propagates to `start()` or `stop()`, that Aurelia instance enters a terminal state.

## Solution

Return only the Promise for work started inside the hook. Invoke and await low-level controller transitions from code outside the lifecycle hooks that participate in them.

Standard component composition coordinates these transitions automatically. If its public APIs produce AUR0509, capture a minimal reproduction for the Aurelia team.
