# AUR0509: Lifecycle Dependency Cycle

## Error Message

`AUR0509: Controller at <controller> created a lifecycle dependency cycle: <reason>.`

## Description

Aurelia detected a controller transition that would wait for itself. This can happen when a lifecycle hook returns its controller's current activation or deactivation result. It can also happen when a child hook returns an ancestor transition that is waiting for the child.

The transition throws or rejects with AUR0509, replacing the dependency deadlock with a concrete controller name and reason. Treat the affected controller graph as terminal.

## Solution

Let the active controller transition own its subtree. Return the asynchronous work started by the hook itself. Await low-level controller transitions from code outside the lifecycle hooks that participate in those transitions.

The `<controller>` and `<reason>` fields identify the cycle. Standard component composition should coordinate these transitions automatically, so a public-API reproduction is useful for a framework report.
