# AUR0510: Controller Disposal During a Lifecycle Transition

## Error Message

`AUR0510: Cannot dispose controller <controller> while a lifecycle operation is running in its owned subtree.`

## Description

Low-level code called `Controller.dispose()` while this controller or one of its dynamically owned descendants was activating or deactivating. Aurelia keeps the controller graph intact so the active transition can finish safely.

## Solution

Await the result of `activate()` or `deactivate()` before calling `dispose()`. For an application root, complete the application shutdown first:

```typescript
await aurelia.stop(true);
aurelia.dispose();
```

Routing, template controllers, and `<au-compose>` coordinate their owned views automatically. A reproduction that reaches AUR0510 through those public APIs indicates a framework integration issue.
