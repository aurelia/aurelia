# AUR0510: Controller Disposal During a Lifecycle Transition

## Error Message

`AUR0510: Cannot dispose controller <controller> while a lifecycle operation is running in its owned subtree.`

## Description

Low-level code called `Controller.dispose()` before this controller or one of its hosted descendants finished activating or deactivating. The dispose call ends with AUR0510, leaving the controller in place so the active transition can settle.

## Solution

Await the result of `activate()` or `deactivate()` before calling `dispose()`. For an application root, complete the application shutdown first:

```typescript
await aurelia.stop(true);
aurelia.dispose();
```

Standard routing and composition coordinate their hosted views automatically. If those public APIs produce AUR0510, capture a minimal reproduction for the Aurelia team.
