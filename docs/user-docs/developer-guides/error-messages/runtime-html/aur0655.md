# AUR0655: Recursive Watcher Side Effect

## Error Message

`AUR0655: Possible infinitely recursive side-effect detected in a watcher`

## Description

A computed watcher re-evaluated more than 100 times without reaching a stable value. A common cause is a watcher callback that assigns a new value to one of its own dependencies on every run. A watched function that mutates observed state can create the same cycle.

## Solution

Keep the watched function focused on reading and computing a value. Make callback updates converge to a stable state, or write to state outside the dependency chain being watched.

Start with the watcher named in the stack trace. Trace the properties it reads and the properties its callback changes until the cycle becomes visible.
