# AUR0771: Aurelia Must Be Stopped Before Disposal

## Error Message

`AUR0771: The aurelia instance must be fully stopped before it can be disposed`

## Description

`Aurelia.dispose()` was called while the application was running, starting, or stopping. Disposal releases the application container, so Aurelia requires the active lifecycle transition to settle first.

A never-started idle instance can be disposed directly.

## Solution

Await `stop()` before disposing the `Aurelia` instance. `await` works for both the synchronous and asynchronous return paths:

```typescript
await aurelia.stop(true);
aurelia.dispose();
```

Share this shutdown sequence when several parts of an application can request teardown.

If `start()` or `stop()` already failed, AUR0771 is a secondary error from attempting disposal on that terminal application graph. Return to the original lifecycle or app-task error and fix it first. Create a fresh Aurelia instance when the application is started again.
