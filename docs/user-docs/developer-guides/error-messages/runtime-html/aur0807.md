# AUR0807: Composition Controller Was Already Used

## Error Message

`AUR0807: Composition has already been activated/deactivated. Id: <controller>`

## Description

`ICompositionController.activate()` was called after that composition controller had already started or stopped. A composition controller represents one composed view and its activation is single-use.

`<au-compose>` serializes normal bindable updates. This error is most often actionable in integration code that obtains the controller through the `composition` bindable and calls `activate()` directly.

## Solution

Let `<au-compose>` activate the controller. Change `component`, `template`, or `model` to update the composition. Use `composition.update(model)` for an explicit model update.
