# AUR0808: Composition Was Already Deactivated

## Error Message

`AUR0808: Composition has already been deactivated.`

## Description

`ICompositionController.deactivate()` was called more than once for the same composed view. This commonly occurs when application code deactivates the controller obtained through the `composition` bindable while `<au-compose>` still owns that composition. A later replacement or parent teardown then reaches the same one-shot controller.

This error is most often actionable in integration code that obtains the controller through the `composition` bindable and manages it directly.

## Solution

Leave deactivation under `<au-compose>` ownership. Change its `component` or `template` bindable to replace the composition, or remove the owning `<au-compose>` through the surrounding view. Use `composition.update(model)` for an explicit model update.

If standard `<au-compose>` usage produces this error, capture the stack trace and provide a minimal reproduction.
