# AUR0808: Composition Was Already Deactivated

## Error Message

`AUR0808: Composition has already been deactivated.`

## Description

`ICompositionController.deactivate()` was called more than once for the same composed view. `<au-compose>` owns deactivation of its composition controller. Check code that obtains the controller through the `composition` bindable and calls `deactivate()` directly. A later replacement or parent teardown then reaches the same single-use controller.

## Solution

Leave deactivation under `<au-compose>` ownership. Change its `component` or `template` bindable to replace the composition, or remove the owning `<au-compose>` through the surrounding view. Use `composition.update(model)` for an explicit model update.
