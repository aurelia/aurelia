# AUR0809: Invalid AuCompose Flush Mode

## Error Message

`AUR0809: Invalid flushMode "<value>" on <au-compose />. Only "sync" or "async" allowed.`

## Description

The `flush-mode` bindable on `<au-compose>` received a value outside its two supported modes.

## Solution

Use `sync` for immediate composition updates or `async` to batch related bindable changes into the next change-processing turn:

```html
<au-compose component.bind="currentComponent" flush-mode="async"></au-compose>
```

When the value is bound, ensure the expression resolves to the lowercase string `'sync'` or `'async'`.
