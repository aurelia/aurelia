# AUR0825: defer Branch Without a defer

## Error Message

`AUR0825: Invalid [defer-placeholder] usage, it should follow a [defer] or another branch of a [defer]. A template controller written before [defer] on the same element, such as [if], wraps it and hides it from the branches, so move that template controller to a parent element.`

The name in brackets is the branch that failed to link: `defer-placeholder`, `defer-loading` or `defer-error`.

## Description

The branches of a [`defer` block](../../../templates/deferred-rendering.md) link to the block the same way `else` links to `if`: each branch must directly follow the `defer` element, or another branch of the same `defer`.

## Cause

1. The branch isn't adjacent to a `defer` element or one of its branches. Another element with a template controller or custom attribute between them breaks the chain.
2. The branch is used on its own, without a `defer`.
3. The branch is nested inside the `defer` element instead of following it.
4. A template controller comes before `defer` on the same element, as in `<section if.bind="show" defer>`. That template controller wraps the `defer`, so the branches follow the `if` instead.

## Solution

Place the branches directly after the `defer` element. Text and plain elements without bindings between them are fine. Move a template controller written before `defer` to an element that wraps the block and its branches.

## Example

```html
<!-- Incorrect: the branch is inside the defer block -->
<section defer="viewport">
  <heavy-chart></heavy-chart>
  <div defer-placeholder>Loading chart</div>
</section>

<!-- Correct -->
<section defer="viewport">
  <heavy-chart></heavy-chart>
</section>
<div defer-placeholder>Loading chart</div>
<div defer-error>Couldn't load the chart</div>

<!-- Incorrect: the if wraps the defer, and the branch follows the if -->
<section if.bind="showChart" defer="viewport">
  <heavy-chart></heavy-chart>
</section>
<div defer-placeholder>Loading chart</div>

<!-- Correct -->
<template if.bind="showChart">
  <section defer="viewport">
    <heavy-chart></heavy-chart>
  </section>
  <div defer-placeholder>Loading chart</div>
</template>
```
