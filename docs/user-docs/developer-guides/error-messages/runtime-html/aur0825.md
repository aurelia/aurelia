# AUR0825: Invalid `<au-head>` Child

## Error Message

`AUR0825: Invalid <au-head> child <{{tag}}>. Only <title>, <meta>, <link>, <script>, <base>, <let> and <template> are allowed, and no text.`

Where `{{tag}}` is the name of the element that was found inside `<au-head>`, or `#text` for text that isn't whitespace.

## Description

`<au-head>` renders its children into `document.head` through `IHead`. Only elements that belong in the document head can be managed that way, so any other element is rejected when the template is compiled.

## Example Trigger

```html
<!-- ❌ a <div> can't go into the document head -->
<au-head>
  <title>${product.name}</title>
  <div class="note">Draft</div>
</au-head>
```

## Correct Usage

Keep page content outside `<au-head>`. Use `<template>` with a template controller to group or repeat head tags:

```html
<au-head>
  <title>${product.name}</title>
  <template if.bind="product.draft">
    <meta name="robots" content="noindex">
  </template>
</au-head>
<div class="note" if.bind="product.draft">Draft</div>
```

See [Managing the document head](../../../getting-to-know-aurelia/head-management.md).
