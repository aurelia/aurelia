# AUR0826: Multiple Application Task Failures

## Error Message

`AUR0826: Multiple application tasks failed during the "<phase>" phase.`

## Description

Several `AppTask` callbacks in one lifecycle phase failed. Aurelia starts callbacks in registration order without waiting for each returned Promise to settle. More than one task can therefore be running when one rejects. The same error can occur when an earlier asynchronous task rejects after the next callback throws synchronously.

Aurelia waits for every task that already started, then reports the failures in task registration order. A synchronous throw prevents later callbacks in the phase from starting.

This is a native `AggregateError`. Its `errors` array contains the original values thrown or rejected by the tasks.

## What to Check

Start with `error.errors[0]`. The `<phase>` value identifies the relevant [app task lifecycle phase](../../../getting-to-know-aurelia/app-tasks.md#lifecycle-phases). Review each application and plugin task registered for that phase.

The application transition is terminal. Fix every entry before creating and starting a fresh Aurelia instance.
