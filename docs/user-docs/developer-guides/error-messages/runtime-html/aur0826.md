# AUR0826: Interpolation in an `<au-head>` Script

## Error Message

`AUR0826: Interpolation inside an <au-head> <script> is not supported because the value would not be escaped. Use json.bind="value" to render JSON safely.`

## Description

The content of a `<script>` element is raw text. An interpolated value containing `</script>` would end the element early and let the rest of the value be parsed as HTML, which is an injection risk, especially in server-rendered pages. `<au-head>` therefore rejects `${}` inside a `<script>`.

## Example Trigger

```html
<!-- ❌ product.name is written into the script unescaped -->
<au-head>
  <script type="application/ld+json">
    { "@type": "Product", "name": "${product.name}" }
  </script>
</au-head>
```

## Correct Usage

Build the object in the view model and bind it with `json.bind`. The value is serialized with `JSON.stringify`, and `<`, `>` and `&` are escaped:

```html
<au-head>
  <script type="application/ld+json" key="product" json.bind="productSchema"></script>
</au-head>
```

```typescript
export class ProductPage {
  product = { name: 'Kettle' };

  get productSchema() {
    return { '@context': 'https://schema.org', '@type': 'Product', name: this.product.name };
  }
}
```
