# AUR0826: Multiple Application Task Failures

## Error Message

`AUR0826: Multiple application tasks failed during the "<phase>" phase.`

## Description

Several `AppTask` callbacks in one lifecycle phase failed. This happens when multiple asynchronous tasks have already started before their failures become observable, or when an earlier asynchronous task rejects after a later task throws synchronously.

Aurelia observes every task that already started, then reports the failures in task registration order. A synchronous throw stops admission of later tasks in the phase.

This is a native `AggregateError`. Its `errors` array contains the original values thrown or rejected by the tasks.

## What to Check

Start with `error.errors[0]`. The `<phase>` value identifies the relevant [app task lifecycle phase](../../../getting-to-know-aurelia/app-tasks.md#lifecycle-phases). Review each application and plugin task registered for that phase.

The application transition has failed and should be treated as terminal. Fix every entry before running the application again.
