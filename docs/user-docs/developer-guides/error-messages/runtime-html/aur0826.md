# AUR0826: defer Trigger Without an Element to Watch

## Error Message

`AUR0826: The "viewport" trigger of [defer] in <report-page> needs an element to watch. Add a [defer-placeholder] with an element, or bind the "target" of [defer].`

## Description

The `viewport`, `interaction` and `hover` triggers of a [`defer` block](../../../templates/deferred-rendering.md) watch an element. The block's own location is a comment node, which can't be observed or receive events, so these triggers watch the first element of the `defer-placeholder` branch, or the element bound to `target`.

## Cause

1. The block has no `defer-placeholder` branch and no `target`.
2. The `defer-placeholder` branch only contains text, so it has no element to watch.
3. `target` is bound to a reference that is `null` or `undefined` when the block is attached.

## Solution

Add a placeholder with an element, or bind `target` to an element that exists when the block is attached.

## Example

```html
<!-- Incorrect: nothing to watch -->
<section defer="viewport">
  <heavy-chart></heavy-chart>
</section>

<!-- Correct: the placeholder is watched -->
<section defer="viewport">
  <heavy-chart></heavy-chart>
</section>
<div defer-placeholder class="chart-skeleton"></div>

<!-- Correct: an explicit target -->
<h2 ref="chartHeading">Sales</h2>
<section defer="on: viewport; target.bind: chartHeading">
  <heavy-chart></heavy-chart>
</section>
```
