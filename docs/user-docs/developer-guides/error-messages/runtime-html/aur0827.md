# AUR0827: Unknown defer Trigger

## Error Message

`AUR0827: Unknown [defer] trigger "scroll" in <report-page>. Expected one of: idle, viewport, interaction, hover, timer, immediate.`

## Description

The `on` and `prefetch` options of a [`defer` block](../../../templates/deferred-rendering.md) take a comma or space separated list of triggers, or an array of them. One of the names isn't a trigger `defer` knows.

## Cause

1. A typo in a trigger name.
2. An option written as a trigger, for example `defer="viewport; 200px"` instead of `defer="on: viewport; margin: 200px"`.
3. A condition passed to `on`. Use `when.bind` to render on a condition.

## Solution

Use one of `idle`, `viewport`, `interaction`, `hover`, `timer` or `immediate`, and pass the other options by name.

## Example

```html
<!-- Incorrect -->
<div defer="scroll">...</div>

<!-- Correct -->
<div defer="on: viewport; margin: 200px">...</div>
<div defer="when.bind: isReady">...</div>
```
