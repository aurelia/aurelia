# AUR0828: Invalid defer load

## Error Message

`AUR0828: The "load" of [defer] in <report-page> must be a function, or an array of functions, that loads the dependencies when called, such as () => import('./chart'). Received: a promise.`

## Description

The `load` option of a [`defer` block](../../../templates/deferred-rendering.md) takes functions, which the block calls when a trigger fires. Calling them later is what keeps the code out of the first render. A promise, a module or any other value can't be called, so the block fails the load with this error. The `defer-error` branch shows it as `$defer.error`, and without that branch it's reported to the console as [AUR0829](aur0829.md).

## Cause

1. The binding calls the import itself, as in `load.bind="import('./chart')"`, which downloads the code while the page binds and passes a promise.
2. The view model calls the loader, as in `load.bind="loadChart()"`.
3. The bound property holds a module, a class or `undefined` in an array, rather than a function.

## Solution

Bind a function, or an array of functions, that start loading when called.

## Example

```html
<!-- Incorrect: loads while binding, and passes a promise -->
<section defer="on: viewport; load.bind: loadChart()">
  <heavy-chart></heavy-chart>
</section>

<!-- Correct -->
<section defer="on: viewport; load.bind: loadChart">
  <heavy-chart></heavy-chart>
</section>
```

```typescript
export class ReportPage {
  loadChart = () => import('./heavy-chart');
}
```
