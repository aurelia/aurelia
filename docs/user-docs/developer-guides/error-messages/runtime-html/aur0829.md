# AUR0829: defer Failed to Load

## Error Message

`AUR0829: [defer] in <report-page> failed to load its dependencies: Failed to fetch dynamically imported module: https://example.com/assets/heavy-chart-4f1c.js`

## Description

A loader of a [`defer` block](../../../templates/deferred-rendering.md) rejected or threw, and the block has no `defer-error` branch to show. The block renders nothing and reports this error through Aurelia's task queue, once per failed load. The message names the element whose template contains the block. The error the loader failed with is the `cause` of this error, which browser consoles show below it with its own stack.

## Cause

1. The network request for the code failed, for example while offline, or after a deployment removed the chunk the page asks for.
2. The loaded module threw while it was evaluated.
3. The `load` of the block isn't a function ([AUR0828](aur0828.md)).

## Solution

Look at the `cause` of the error to see why the load failed. To let users recover, add a `defer-error` branch with a retry. With that branch the error is shown there instead of being reported.

## Example

```html
<section defer="on: viewport; load.bind: loadChart">
  <heavy-chart></heavy-chart>
</section>
<div defer-error>
  Couldn't load the chart.
  <button click.trigger="$defer.retry()">Try again</button>
</div>
```
