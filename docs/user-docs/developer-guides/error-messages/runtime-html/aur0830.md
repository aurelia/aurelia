# AUR0830: Portal Target Has No Parent

## Error Message

`AUR0830: Invalid portal target, position "<position>" needs a target that has a parent node.`

Where `<position>` is `beforebegin` or `afterend`.

## Description

The `portal` attribute places its content relative to the target element. With `position: beforebegin` or `position: afterend` the content goes next to the target, inside the target's parent. If the target has no parent, there is nowhere to put the content.

The portal checks this before it moves anything. When the error comes from a target or position change, the content stays where it was.

## Cause

The resolved target is an element that is not attached anywhere, for example one created with `document.createElement()` and not inserted yet, or one that has been removed from the DOM.

```typescript
export class MyComponent {
  // created, but never inserted into the document
  target = document.createElement('div');
}
```

```html
<div portal="target.bind: target; position: afterend">Portal content</div>
```

## Solution

- Insert the target element into the DOM before the portal attaches or before you bind it.
- Use `position: beforeend` or `position: afterbegin` if you want the content inside the target. Those positions only need the target itself.
- If the target is created later, keep `target` unset or bound to an attached element until it is ready.
