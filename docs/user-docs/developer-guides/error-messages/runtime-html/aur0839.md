# AUR0839: Duplicate Controller Reference on a Node

## Error Message

`AUR0839: Node already has a controller associated with ref "<name>".`

## Description

The same node already has a controller reference registered under `<name>`. Aurelia preserves the existing association and rejects the replacement.

This is usually actionable in renderer or integration code that uses the exported `refs` API. Normal application templates have one controller owner for each node and reference name.

## Solution

Keep the existing reference for the lifetime of its controller. `refs.clear(node)` clears every controller association for the node, so call it only after all controllers that own the node have completed teardown. Editing `node.$au` does not clear the backing reference map.
