# AUR0840: Missing Nested SSR Template

## Error Message

`AUR0840: SSR hydration error: missing nested template at index <index>.`

## Description

An SSR definition contains a template-controller instruction whose `templateIndex` falls outside the translated nested template table. `hydrateSSRDefinition()` stops before publishing a client definition.

This is an SSR artifact integrity error. It commonly indicates that `definition.nestedTemplates` and `nestedHtmlTree` came from different builds or that generated data was edited or truncated.

## What to Check

Regenerate the complete serialized definition payload. Keep the server output and client assets from the same build, then clear caches that can retain an older payload. If generation still produces the mismatch, report the payload and its source template with the Aurelia package versions.
