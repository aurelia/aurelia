# AUR0841: Unknown SSR Instruction Type

## Error Message

`AUR0841: SSR hydration error: unknown instruction type <type>.`

## Description

`hydrateSSRDefinition()` received a serialized instruction type that the client runtime cannot translate. Hydration stops before publishing a client definition.

This is an SSR wire-format compatibility error. It usually indicates server and client package version drift or a generator emitting an unsupported instruction.

## What to Check

Align the Aurelia versions used to generate and hydrate the SSR definition. Rebuild the server output and client assets together, then clear cached HTML and definition payloads. If the same build emits `<type>`, report the serialized instruction and its source template.
