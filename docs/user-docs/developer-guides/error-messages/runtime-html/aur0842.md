# AUR0842: Missing SSR Expression

## Error Message

`AUR0842: SSR hydration error: expression <id> was not found.`

## Description

A serialized SSR instruction references an expression ID that is absent from the definition's `expressions` table. `hydrateSSRDefinition()` stops before publishing a client definition.

This is an SSR artifact integrity error. It usually means the instruction rows and expression table came from different generated payloads or one part was truncated.

## What to Check

Regenerate the serialized definition as one payload. Keep the server output and client assets from the same build, then clear cached HTML and definition data. If `<id>` remains missing, report the payload and its source template with the Aurelia package versions.
