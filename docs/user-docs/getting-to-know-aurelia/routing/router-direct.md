# @aurelia/router-direct

This page links to documentation for existing applications using `@aurelia/router-direct`. For a new application, use the maintained [`@aurelia/router`](./aurelia-router.md), which supports component-owned routes, nested layouts, named viewports, and contextual navigation.

The packages share some familiar template names, including `load` and `<au-viewport>`, but have separate configuration and navigation APIs. Check your imports before using a recipe. See [Choosing the right Aurelia router](./choosing-a-router.md) for the package distinction.
